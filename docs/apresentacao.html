GROVE

A linguagem de programação em que as palavras-chave são os cheats de GTA San Andreas.

Arquivos .cj, de Carl Johnson. Python 3.10+, sem nenhuma dependência.

01 · a linguagem

Dez palavras reservadas

HESOYAMdeclara variável
TURNUPTHEHEATif
BRINGITONelse if
TURNDOWNTHEHEATelse
KANGAROOwhile
GOODBYECRUELWORLDbreak
HELLOLADIESprint
CJPHONEHOMElê um inteiro
FULLCLIPtrue
GHOSTTOWNfalse

O resto é sintaxe estilo C: { } delimita bloco, ; termina instrução, ( ) agrupa, ! && || são os lógicos. Três tipos: inteiro, string e booleano, sem conversão implícita.

02 · um programa

Fatorial de 5

# fatorial de 5
HESOYAM n = 5;
HESOYAM r = 1;
KANGAROO (n > 1) {
    r = r * n;
    n = n - 1;
}
HELLOLADIES r;
$ python -m grove examples/fatorial.cj
120

Cada execução termina como no jogo: Mission passed! no sucesso, Wasted no erro léxico, Busted no semântico, com o clipe de áudio do jogo quando os .wav estão na pasta.

4 erros sintáticos
  • ◆Descida recursiva, LL(1)Um método por regra da gramática; cada regra decide olhando só o próximo token.
  • ◆Precedência na cadeia de regrasou → e → igualdade → comparação → termo → fator → unário → primário, tudo associativo à esquerda.
  • ◆Nada de else ambíguoBloco é sempre { }, então o pendente não existe. BRINGITON é açúcar: vira um if aninhado.
  • ◆Recuperação e sugestãoO parser segue depois do erro e a distância de edição acha o cheat ou a variável mais parecida.

4 erros semânticos
  • ◆Tabela de símbolosPilha de escopos, um por bloco. Cada símbolo guarda tipo, escopo, posição, nome único e se foi lido.
  • ◆Tipos sem conversão implícita1 + "a" é erro; a condição do if e do while tem de ser booleana.
  • ◆Três tipos, nenhum floatInteiro, string e booleano. Com float, o Python (double de 64 bits) e o AVR do Mega (sem FPU) parariam de dar a mesma saída.
  • ◆Todos os erros de uma vezPercorre o programa inteiro antes de reclamar. Não para no primeiro.
  • ◆Anota a ASTCada expressão ganha tipo e cada variável ganha seu símbolo. É dessa AST que saem a TAC, o Python e o C++.

Código de três endereços

  • ◆Uma quádrupla por instruçãoQuad(op, arg1, arg2, result): no máximo um operador, temporários t1…tn e rótulos L1…Ln.
  • ◆Sem escopo e sem aninhamentoAs variáveis usam o nome único da tabela de símbolos, porque a TAC é linear.
  • ◆Curto-circuito explícito&& e || viram desvios; break vira um goto para o fim do laço.
  • ◆ExecutávelA TAC roda num executor próprio, o que garante que ela faz o mesmo que o interpretador.

09 · etapa 5

Duas linguagens de saída

Python · --python

n = 5
r = 1
while n > 1:
    r = r * n
    n = n - 1
print(r)

Sai da AST, não da TAC: Python não tem goto, e o if/while da árvore vira if/while direto. Dá para canalizar: --python | python3.

Arduino C++ · --mega

void setup() {
  Serial.begin(115200);
  _inicializar();
  long estrelas = 0L;
  _procurado(estrelas);
  while (true) {
    estrelas = _linha();   // CJPHONEHOME
    _procurado(estrelas);
    Serial.println(estrelas);
  }
}

Mesma AST, outro alvo: o C++ do Mega 2560, com CJPHONEHOME lendo a serial e o nível de procurado acendendo o HUD.

11 · a volta completa

O jogo acendendo os LEDs

CJPHONEHOME é a primeira expressão da Grove que lê: ela espera a próxima linha da entrada. No PC é o teclado; na placa, a serial. O mesmo programa serve aos dois.

0,3 s entre a estrela aparecer na tela e o LED acender.
